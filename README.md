# AUTORA website prototype

A static Turkish/English landing-page prototype for AUTORA.

## Deploy to Vercel
1. Create a GitHub repository (for example `autora-website`).
2. Upload `index.html` to the repository root and commit.
3. Sign in to Vercel with GitHub and import the repository.
4. Select **Other** as framework. Leave Build Command and Install Command empty.
5. Set Output Directory to `.` if Vercel asks, then deploy.

The valuation calculator is illustrative demo logic only. It does not use live vehicle-market data, a database, authentication, payments, or a backend.
